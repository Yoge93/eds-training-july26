Page Content

This is a demo page showing how the header with dynamic navigation works.

The header includes:

  • Logo (left side) - clickable, configurable link destination
  • Navigation Menu (center) - dynamically parsed from the table above
  • Search Bar (right side) - with configurable action URL
  • Mobile Hamburger Menu - appears at screen widths < 900px

How It Works

Content Structure: Authors create a table with two columns:

  1. Column 1: Link element (e.g., <a href="/page">Link text</a>)
  2. Column 2: Label text (optional, or can use link text)

Block Model: The header block has authorable fields for:

  • Logo Image (reference to image asset)
  • Logo Alt Text
  • Logo Link Destination (URL or page link)
  • Search Placeholder Text
  • Search Form Action URL

JavaScript: The header.js extracts the logo from the block and navigation items from the table, then builds a responsive navigation structure with hamburger menu for mobile.

Testing Instructions

Desktop (≥900px):

  • Logo should appear on the left
  • Navigation items should appear in a row
  • Search bar should appear on the right
  • Hamburger menu should be hidden

Mobile (<900px):

  • Hamburger menu button should appear
  • Navigation items should be hidden until menu is clicked
  • Search bar should be accessible in the menu
  • Clicking hamburger should toggle menu visibility

Interactivity:

  • Click logo → navigates to configured URL
  • Click nav items → navigates to respective pages
  • Type in search → submit goes to configured search action URL with query parameter
