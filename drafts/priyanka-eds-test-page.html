Navigation Block Features

✓ Fully Authorable

All navigation elements (logo, items, search) are configured through the block model in Universal Editor. No content parsing required.

✓ Responsive Design

Desktop view shows logo, nav items, and search horizontally. Mobile view (<900px) collapses into hamburger menu.

✓ Accessible

Full keyboard navigation support, ARIA labels, and semantic HTML for screen readers.

✓ Flexible

Easy to add, remove, or reorder navigation items without touching the code.

🧪 Testing Instructions

Desktop Testing (≥900px)

  1. Resize browser to desktop width (1200px or wider)
  2. Verify you see:
    • Logo on the left side with MyCompany branding
    • Navigation items in a horizontal row in the center
    • Search bar on the right side with magnifying glass icon
    • NO hamburger menu button

Mobile Testing (<900px)

  1. Open DevTools (F12) and toggle responsive mode
  2. Set width to mobile size (e.g., 375px)
  3. Verify you see:
    • Hamburger menu icon on the left

  5. Click a nav item → should navigate to that page
  6. Click hamburger again → menu closes
  7. Press ESC key → menu should close

Keyboard Accessibility Testing

  1. Press Tab to navigate through navigation items
  2. Press Enter on a nav item → navigates to that page
  3. Press Escape when mobile menu is open → closes menu
  4. Tab should properly focus on search input and submit button

Navigation Item Structure - Text & Link Nodes

Each navigation item is made up of two separate authorable nodes:

1. Link Node (Authorable)

<a href="...">...</a>

Authors select or create a link using the Navigation Link field. This node stores the URL/page destination.

2. Text Node (Authorable)

<p>...</p> or <span>...</span>

Authors enter display text using the Navigation Text field. This is the text that users see and can click.

Example Markup:

<div class="nav-item">
  <!-- Link Node (authorable) -->
  <a href="/products">Products</a>
  
  <!-- Text Node (authorable) -->
  <p>Products</p>
</div>

How Authors Configure Each Node:

Node Field Name Input Type Example
Link Node Navigation Link aem-content (link picker) /products or https://example.com
Text Node Navigation Text text (text input) Products

Logo Configuration Section

{
  "component": "section",
  "name": "logo_section",
  "label": "Logo Configuration",
  "fields": [
    {
      "component": "reference",
      "name": "logoImage",
      "label": "Logo Image"
    },
    {
      "component": "text",
      "name": "logoAlt",
      "label": "Logo Alt Text"
    },
    {
      "component": "aem-content",
      "name": "logoLink",
      "label": "Logo Link Destination"
    }
  ]
}

Navigation Items Section

{
  "component": "section",
  "name": "nav_items_section",
  "label": "Navigation Items",
  "fields": [
    {
      "component": "reference",
      "name": "navItems",
      "label": "Navigation Items",
      "multi": true,
      "filter": "nav-item"
    }
  ]
}

Navigation Item Component

{
  "id": "nav-item",
  "fields": [
    {
      "component": "aem-content",
      "name": "navItemLink",
      "label": "Navigation Link",
      "required": true,
      "description": "Select or create a link (e.g., internal page or external URL) - this is the authorable link node"
    },
    {
      "component": "text",
      "valueType": "string",
      "name": "navItemLabel",
      "label": "Navigation Text",
      "required": true,
      "description": "Enter the display text for this navigation item - this is the authorable text node"
    }
  ]
}

Each navigation item has two clearly separate, authorable fields:

  • Navigation Link — The URL or page destination (link node)
  • Navigation Text — The visible text users see and click (text node)

How to Modify Navigation in Universal Editor

  1. Open this page in Universal Editor
  2. Click on the Navigation block
  3. To change the logo:
    • Expand "Logo Configuration" section
    • Update logo image, alt text, and link destination
  4. To add/edit navigation items:
    • Expand "Navigation Items" section
    • Click "+" to add new nav item
    • Select or create a nav-item component
    • Configure the two authorable nodes:
      • Navigation Link (link node) — Click link picker, select page or enter URL
      • Navigation Text (text node) — Enter the display text (e.g., "Products", "Contact")
    • Drag to reorder or click "X" to delete
  5. To change search settings:
    • Expand "Search Configuration" section
    • Update placeholder text and form action URL
  6. Save and publish your changes

Troubleshooting

Navigation not showing?

  • Check that nav-item divs exist in the page markup
  • Verify each nav-item has both <a> (link) and <p> (label) elements
  • Check browser console (F12) for JavaScript errors

Hamburger menu not appearing on mobile?

  • Ensure viewport width is less than 900px
  • Clear browser cache (Ctrl+Shift+R in Chrome)
  • Check that header.css is being loaded

Search not working?

  • Verify the search form action URL is correct
  • Check that /search page exists or is properly configured
  • Test by typing text and pressing Enter

Styling looks off?

  • Check that header.css file is loaded
  • Verify no CSS conflicts with page styles
  • Clear browser cache and reload
