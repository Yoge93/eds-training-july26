Navigation Block - Fully Authorable

This header uses the new Navigation block with fully authorable components. Authors configure all content directly in the block without needing separate content sections.

Block Structure

The Navigation block consists of three main authorable sections:

  1. Logo Configuration
    • logoImage - Reference field to select logo image
    • logoAlt - Alt text for accessibility
    • logoLink - Destination URL/page when logo is clicked
  2. Navigation Items
    • navItems - Multi-value reference field for nav-item components
    • Each nav-item component has:
      • navItemLink - Link destination (aem-content)
      • navItemLabel - Display label text
  3. Search Configuration
    • searchPlaceholder - Text shown in search input box
    • searchAction - URL where search form will be submitted

How Authors Use This

In Universal Editor, authors follow these steps:

  1. Add Navigation Block to a page section
  2. Configure Logo Section:
    • Click "Logo Image" field and select/upload logo image
    • Set "Logo Alt Text" for accessibility
    • Set "Logo Link Destination" to where logo should link (e.g., homepage)
  3. Add Navigation Items:
    • In "Navigation Items" section, click "+" to add new nav item
    • Select or create a nav-item component
    • Configure each nav item:
      • Set link destination (page or URL)
      • Set label text (e.g., "Products", "Contact")
    • Repeat for all navigation items
  4. Configure Search:
    • Set "Search Placeholder Text" (e.g., "Search...")
    • Set "Search Form Action URL" (where search queries go)
  5. Publish - Navigation is live on page

Frontend Rendering

The header.js script automatically:

  1. Extracts logo image and configured link from block content
  2. Finds all nav-item divs and extracts link + label pairs
  3. Reads search configuration from block attributes
  4. Builds responsive navigation structure:
    • Desktop (≥900px): Logo on left | Navigation items in center | Search on right (all visible)
    • Mobile (<900px): Logo and hamburger menu visible | Navigation items hidden in menu
  5. Attaches event listeners for menu toggle, navigation clicks, and search submission

Example: Navigation Item Component

Each navigation item is a separate nav-item component defined in the model:

{
  "id": "nav-item",
  "fields": [
    {
      "component": "aem-content",
      "name": "navItemLink",
      "label": "Link",
      "required": true
    },
    {
      "component": "text",
      "valueType": "string",
      "name": "navItemLabel",
      "label": "Label Text",
      "required": true,
      "description": "Display text for the navigation item"
    }
  ]
}

Authors add multiple nav-item components (Home owners, Products, Get in touch, Resources, Contact, Contractor app) to build the complete navigation.

Advantages of This Approach

  • Fully Authorable: No content parsing or table structures needed
  • Flexible: Easy to add, remove, or reorder navigation items
  • Maintainable: Clear separation between logo config, nav items, and search config
  • Scalable: Can easily extend nav items with additional fields (icon, target, CSS classes, etc.)
  • Accessible: Structured data improves SEO and enables better accessibility features
  • Consistent UX: Universal Editor provides consistent authoring interface

Testing the Navigation

Desktop View (width ≥ 900px):

  • ✓ Logo visible on left side with clickable link
  • ✓ Navigation items displayed horizontally in center
  • ✓ Search bar visible on right side
  • ✓ Hamburger menu button NOT visible

Mobile View (width < 900px):

  • ✓ Hamburger menu button visible on left
  • ✓ Logo visible in center
  • ✓ Navigation items hidden by default
  • ✓ Click hamburger to show/hide navigation menu
  • ✓ Search bar accessible within menu

Interactivity:

  • ✓ Click logo → navigates to configured URL
  • ✓ Click nav item → navigates to configured page
  • ✓ Type search text and press Enter → form submits to configured action URL with query parameter
  • ✓ Press ESC key → closes mobile menu
  • ✓ Tab navigation → keyboard accessible menu items
