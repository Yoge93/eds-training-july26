Welcome to Header Test Page

This is a test page demonstrating the dynamic authorable header.

The header includes:

  • Logo (Left): Clickable logo that links to home page
  • Navigation (Center): Menu items - Home Owners, Products, Get in Touch, Resources, Contact, Contractor App
  • Search Bar (Right): Search functionality with configurable placeholder and action
  • Mobile Menu: Hamburger menu on mobile devices (< 900px)

How It Works

The header block is completely authorable:

  • Logo image and link can be configured in the block model
  • Navigation items are authored as a table in the page content
  • Search placeholder and form action are configurable
  • Desktop layout shows all items; mobile layout includes hamburger menu
